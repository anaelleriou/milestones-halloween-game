# Jeu Halloween Milestone

## Ouvrir dans VS Code
1. Décompresser le ZIP.
2. Ouvrir le dossier `halloween-game-vscode` dans VS Code.
3. Ouvrir `index.html` dans Chrome, ou utiliser l’extension VS Code Live Server.

## Activer le classement partagé avec Supabase
Les propositions sont enregistrées dans Supabase pour calculer le classement. Les mots proposés sont affichés uniquement dans l’historique local du navigateur qui les a saisis. Il faut configurer un projet Supabase avant de mettre le site en ligne.

1. Créez un projet sur [supabase.com](https://supabase.com/).
2. Dans le SQL Editor du projet, exécutez :

```sql
create table if not exists public.game_guesses (
  id bigint generated by default as identity primary key,
  name text not null,
  word text not null,
  degree integer not null check (degree between 0 and 100),
  label text not null,
  created_at timestamptz not null default now()
);

create unique index if not exists game_guesses_one_per_first_name_per_day
  on public.game_guesses (
    lower(btrim(name)),
    ((created_at at time zone 'Europe/Paris')::date)
  );

alter table public.game_guesses enable row level security;

create policy anyone_can_add_game_guesses
  on public.game_guesses for insert
  to anon, authenticated
  with check (true);

revoke select on public.game_guesses from anon, authenticated;

create or replace function public.get_game_leaderboard()
returns table (name text, degree integer, label text)
language sql
stable
security definer
set search_path = ''
as $$
  select ranked.name, ranked.degree, ranked.label
  from (
    select distinct on (pg_catalog.lower(pg_catalog.btrim(g.name)))
      g.name, g.degree, g.label
    from public.game_guesses as g
    order by pg_catalog.lower(pg_catalog.btrim(g.name)), g.degree desc, g.created_at asc
  ) as ranked
  order by ranked.degree desc
  limit 30;
$$;

revoke all on function public.get_game_leaderboard() from public;
grant execute on function public.get_game_leaderboard() to anon, authenticated;
```

3. Dans Supabase, ouvrez **Project Settings → API** et copiez l’URL du projet et la clé `anon`/`publishable` publique. Collez-les dans `config.js`, dans les champs `supabase.url` et `supabase.anonKey`.
4. Publiez les fichiers du site sur votre hébergeur habituel. Gardez la clé `anon`/`publishable` côté navigateur ; ne mettez jamais la clé `service_role` dans le site.

Les visiteurs peuvent ajouter des propositions, mais ne peuvent pas lire la table contenant les mots. Le classement utilise une fonction qui ne renvoie que les noms/pseudos, degrés et étiquettes. Les propositions personnelles restent dans le stockage local du navigateur ; le classement est actualisé automatiquement toutes les 15 secondes. Le score étant calculé dans le navigateur, il peut être falsifié par un visiteur déterminé ; pour un classement avec scores fiables, le calcul devra être déplacé côté serveur.

Une seule proposition par nom complet ou pseudo et par jour est imposée par un index unique dans la base, selon le jour de Paris ; les majuscules et espaces au début/à la fin sont ignorés. Le nom ou pseudo est mémorisé sur l’appareil après la première tentative pour préremplir le formulaire. Cette règle ne vérifie toutefois pas l’identité : chacun doit choisir un nom complet ou pseudo qui lui est propre, et quelqu’un pourrait saisir l’identifiant d’une autre personne. Sur un appareil partagé, chaque joueur doit modifier le champ avant de proposer.

Si vous avez déjà exécuté l’ancien SQL avec une politique de lecture publique, exécutez cette migration dans le SQL Editor pour masquer les réponses et fournir le classement public sans les mots proposés. Elle ajoute aussi l’index de limite quotidienne s’il n’existe pas encore :

```sql
create unique index if not exists game_guesses_one_per_first_name_per_day
  on public.game_guesses (
    lower(btrim(name)),
    ((created_at at time zone 'Europe/Paris')::date)
  );

drop policy if exists "Anyone can read game guesses" on public.game_guesses;
drop policy if exists anyone_can_read_game_guesses on public.game_guesses;
revoke select on public.game_guesses from anon, authenticated;

create or replace function public.get_game_leaderboard()
returns table (name text, degree integer, label text)
language sql
stable
security definer
set search_path = ''
as $$
  select ranked.name, ranked.degree, ranked.label
  from (
    select distinct on (pg_catalog.lower(pg_catalog.btrim(g.name)))
      g.name, g.degree, g.label
    from public.game_guesses as g
    order by pg_catalog.lower(pg_catalog.btrim(g.name)), g.degree desc, g.created_at asc
  ) as ranked
  order by ranked.degree desc
  limit 30;
$$;

revoke all on function public.get_game_leaderboard() from public;
grant execute on function public.get_game_leaderboard() to anon, authenticated;
```

## Fichiers à modifier
- `config.js` : textes, dates, couleurs, énigmes et niveaux.
- `dictionary.js` : réponses exactes, mots connus, degrés et familles de concepts.
- `style.css` : apparence du site.
- `index.html` : structure de la page.
- `game.js` : fonctionnement du jeu.

## Important
Le classement nécessite une connexion internet et un projet Supabase correctement configuré. Le nom ou pseudo et l’historique personnel sont mémorisés localement dans le navigateur.
